**域名相关知识（查错网科普）**：国际域名由 IANA 负责分配；whois 服务器开放 43 接口，可通过 whois 协议查询顶级域名下某域名是否被注册、注册人、注册时间等信息；域名服务器（name server）是整个网站访问的基础，域名过期或屏蔽后注册机构会同步删除 DNS 解析记录导致网站打不开；DNSSEC 是 DNS 扩展安全验证协议，用于解决域名劫持问题，国内 DNS 服务器少有支持；DANE 协议在 DNSSEC 基础上解决域名证书恶意颁发伪造问题，将站点 HTTPS 证书签名部署在 DNS 中。
