**DNS.iCoA.CN** 是一个持续维护的免费公共 DNS 地址大全页，将 IPv4 / IPv6 / DoT / DoH 集中在一个页面，并附 DNS/NTP/Tracker/Hosts 等其它工具。页面主要栏目：国内 DNS、海外 DNS、教育网 DNS、DNS 知识。下方按服务商整理（含页面提供的部分地址）：

- **腾讯 DNS (DNSPod)**：国内连通性与稳定性较好，海外也可用；支持 IPv4/IPv6 与 DoT/DoH。
- **阿里 DNS (Alidns)**：国内连通性较好，海外部分地区不佳；提供 IPv4/IPv6 与 DoT/DoH。
- **百度 DNS**：提供一组 IPv4 与 IPv6；网友反馈百度 IPv6 已停用、无法正常解析。
- **字节跳动 TrafficRoute DNS**（火山引擎）：仅 IPv4：`180.184.1.1`、`180.184.2.2`。
- **360 安全 DNS**：提供 IPv4 与 DoT/DoH（分电信/铁通/移动、联通两套 IPv4 地址）。
- **中国电信 / 联通 / 移动 IPv6 DNS**：各省分配不同，自动分配本地 DNS 更快；页面列出河北/广东/山东电信、安徽/重庆联通、河南/安徽移动等地区地址。
- **114DNS**（南京信风）：仅 IPv4，纯净版 `114.114.114.114`、`114.114.115.115`，另有安全版（拦截钓鱼/病毒/木马）与家庭版（拦截色情）。
- **CNNIC DNS**：中国互联网络信息中心提供，支持 IPv4/IPv6；网友反馈其 IPv6 已无法解析、官网已查不到该 IP。
- **Yeti DNS**：WIDE/TISF/BII 发起的纯 IPv6 公益 DNS 项目，近期被反馈服务不稳定/不可用。
- **OneDNS**（北京微步在线）：提供 IPv4 `52.80.66.66`、`117.50.22.22` 等，另有 IPv6/DoH/DoT；纯净版已停。
- **Hi!XNS DNS**：嘉兴艾泰德提供，已测试无法解析、不能使用（`40.73.101.101`）。
- **TWNIC DNS Quad 101**：台湾网络资讯中心，IPv4/IPv6，台北 101 命名，新增 DoH。
- **HiNet 中华电信 DNS**：台湾中华电信，IPv4/IPv6，大陆可用，可能支持 DoH。
- **澳门电讯 CTM**：`202.175.3.8`、`202.175.3.3`。
