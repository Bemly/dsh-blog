### 1、U 盘启动，GUI 模式无法显示

**症状**：制作 unraid 启动 U 盘时勾选 "allow UEFI boot"，启动选第一项（代码模式）一切正常、结尾获得 IP；但选 GUI 模式时，外接显示器代码跑完后屏幕变黑，无法进入 GUI 图形界面。不勾选 UEFI 以 legacy 模式启动时，GUI 模式可正常显示。

**解决办法**：在 go 文件中加入 `modprobe i915` 命令，修改后即可进入 GUI 模式（加载集成显卡驱动）。

操作方式一（终端）：
1. 点 unraid 界面右上角 ">_" 进入终端
2. 输入 `modprobe i915` 回车（运行集成显卡驱动）
3. 输入 `ls /dev/dri`，若出现 `renderD128` 文件则显卡驱动正常
4. `cd /boot/config` → `vi go` → 按 i 编辑 → 输入 `modprobe i915` → 按 esc 输入 `:wq` 保存
5. 重启后每次启动都会加载该驱动

操作方式二（图形化）：在应用商店安装 `config file editor` 插件，它出现在工具页第一项；第一横线处选择 `/boot/config/go`，在对话框中加 `modprobe i915` 一行，点应用即可。

### 2、多网口问题

**症状**：多网口主机启动时，不知道网线该插哪一个口。

**解决办法**：固定一个网口为 unraid 管理网口。unraid 默认 eth0 是系统管理口，但哪个物理网口被定义为 eth0 需要手动指定：
1. 终端输入 `nano /boot/config/network-rules.cfg`，看到所有网卡信息
2. 把想指定为管理口的物理网卡编号改成 eth0，原 eth0 换成其他编号；网卡编号从 0 开始（eth0、eth1……），尽量按顺序不跳号
3. ctrl+x 退出 → y 保存 → `reboot` 生效

识别 MAC：在 unraid 设置-网络设置里查看网卡硬件名称对应的 MAC 地址；主板自带网口与 PCIe 扩展网口名称规律不同，通常把主板自带网口指定为管理口（扩展口名字有顺序规律）。

### 3、Jellyfin 使用英特尔核显实现硬解码、转码

前提：要有英特尔核心显卡（本文不探讨 AMD 核显与独显）。

**第一步：添加核显驱动**（与问题 1 相同）：`modprobe i915` → 确认 `/dev/dri/renderD128` 存在 → 写入 go 文件开机自启。

**第二步：Jellyfin 配置**：Web UI → 三横线 → 控制台 → 播放 → 硬件加速选 `Video Acceleration API (VA API)`，设备选 `/dev/dri/renderD128`，保存退出。按步骤执行即可硬解、可转码。

### 4、硬件直通（直连）

直通即设备不经过 unraid 直接分配给虚拟机。虚拟机里有 host 选项说明设备可直通；更极致做法是在 unraid 系统里启动时屏蔽该设备。可直通设备：网口（需给 unraid 留管理口）、硬盘、独立显卡、WiFi。除网口外其他务必慎重。

作者实例：主板 2 个网口 + PCIe 扩展 4 网口，主板一个网口留给 unraid，其余五个直通（主板另一个给 win10 虚拟机、扩展四个给软路由）；2 个 M.2 接口，一个给 unraid 缓存池，另一个启动屏蔽并在 BIOS 设为启动盘装 win10，实现"不用 unraid 时可当 win10 主机"，同时避免 unraid 里出现未挂载 M.2 被误删。

**操作方法**：工具 → 系统设备 → 勾选要屏蔽的设备 → 点"在引导时对 VFIO 绑定"。

⚠️ 注意：设置 VFIO 绑定后，更换硬件（如主板）时**务必先取消绑定**，否则直通旧硬件的虚拟机无法启动，需进命令行改硬件绑定，非常麻烦；一个启动盘插多台机器不建议屏蔽硬件。

### 5、Win10 虚拟机外接显示器无显示（仅核显、无独显）

1. 安装 win10 虚拟机时显卡选 **VNC**，确保能安装并进入系统
2. 在 VNC 里装好 win10，设置主机名、开启远程桌面，用另一台电脑连一次远程桌面确认可连，然后关闭虚拟机
3. 编辑 win10 虚拟机配置：显卡直接选 **hd630**（无需第二显卡；仅核显时虚拟机调用唯一核显后 VNC 就无显卡可用）；给 hd630 指定 BIOS 驱动 `vbios_gvt_uefi.com`（压缩包含三个文件，hd630 用该文件，hd600/610 试其他两个；下载：百度网盘链接 提取码 3f6c），上传到 unraid 的 isos 文件夹，驱动栏手动填 `/mnt/user/isos/vbios_gvt_uefi.com`
4. 更新配置后重启 win10 虚拟机——外接显示器仍无显示，但 win10 已启动
5. 用另一台电脑远程桌面连入 → 我的电脑 → 管理 → 设备管理 → 更新显卡驱动 → 自动搜索驱动；成功后设备管理器里显示器变为 hd600/610/630，unraid 外接显示器也出现 win10 桌面
6. 重启 win10 后 USB 鼠标无指针：可再远程桌面进去，用驱动精灵补驱动（重点是 Intel 官网核显驱动），再重启即正常

⚠️ 特别提醒：主板多个 HDMI/PD 视频输出口时，win10 启动后不一定会输出到哪个端口，需挨个试。

### 6、miniDLNA 的使用

miniDLNA 是局域网流媒体广播，支持 DLNA 的播放器（索尼电视、Bose 音响等）可直接访问 unraid 指定文件夹播放音视频。现代电视可自行硬解码，不一定需要 Jellyfin 等 Docker，miniDLNA 轻量不占资源。

**关键设置**：网络类型说明里要求 host（直连），但实测无法被电视发现，需用 **custom br0** 给 miniDLNA 分配局域网地址（如 192.168.1.11）才能被发现。可先试 host，无法发现再换 br0。

**两个坑**：
1. 默认只扫描名为 `media`（小写）的文件夹，路径必须 `/mnt/user/media/`；指定到 download/movie/music 等其他文件夹时只在安装时扫描一次，之后更新的文件不会被发现（删了还显示、删了就出错）。解决：把媒体文件夹放到 media 下。
2. 只支持 UTF-8 编码，mp3 标签会乱码；用 MP3tag 把歌曲信息批量转为 UTF-8 即可，顺便整理下载资源的 ID3 信息。

- **缓存池 vs 阵列**（CentWind）：BT 下载直接写阵列会触发校验导致卡顿，缓存池有意义；但默认缓存池写满不会自动写阵列（逻辑较蠢）。
- **Mover 搬运**（lyqalex）：缓存池到阵列的搬运靠 mover 工作，可安装 **Mover Tuning** 插件把计划周期调短（如每小时一次），也可用机械硬盘做 cache 盘满足大文件临时存放。
- **缓存选项"首选"**（JavyLiu）：缓存设置为"首选"会优先写缓存、满了再写阵列，但会持续把缓存占满，适合 appdata、domain 这类文件夹；大文件迁移时系统按"缓存剩余空间"而非阵列剩余空间判断，缓存写满会卡死不动。理想是缓存占用到 95% 时自动触发 mover。
- **Mover Tuning 进阶**（lyqalex 再补充）：`Cron Schedule` 可自定义 mover 检查频率；`Only move at this threshold of used cache space` 设置阈值后，频繁检查不满足阈值就不搬运，不影响阵列磁盘休眠。
- **核显直通补充**（用户 17 楼）：INTEL GPU TOP 插件可替代手动改 go 文件；核显直通/虚拟化参考《IGPU 的显卡虚拟化这次真的来了--基于 unraid》；有用户反馈 win11 12 代 U 用 vbios_gvt_uefi.com 直通成功，但 HDMI 无声音（可能是该驱动问题）。
