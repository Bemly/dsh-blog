【前言】

博主不定期的分享【阿里云盘的资源】，有网友私信给博主说想转存这些资源但是自己阿里云盘的容量不够大装不下，问我怎么办？当然有办法的，土豪哥可以直接充钱扩容空间就完事了，但是如果想不花钱也可以实现，那么今天就说一下不花钱的办法。

![002-10 配图](images/i01-1671522834-1.avif)

【准备工作】

在操作之前，需要准备一下：

1、需要有一个自己的阿里云盘账号，并且在手机安装好阿里云盘APP，登录上去，如果还没注册账号的话现在马上立即去【注册阿里云盘账号】；

2、需要有一台NAS，或者有一台OpenWrt-x86/64的软路由，或者有一台 Linux系统的服务器，并且安装好alist（在群晖NAS安装alist的教程参考【这个】，在Openwrt软路由安装alist的教程参考【这个】），如果还没安装好的话现在马上立即去安装。

【操作步骤】

1、登录到你的alist管理后台（我这安装的版本是alist v3.6.0，理论上所有alist v3.X版本都支持），点左边菜单“存储”，在右边点“添加”按钮；

![002-10 配图](images/i02-1671522835-2.avif)

2、点一下下拉列表；

![002-10 配图](images/i03-1671522835-3.avif)

3、选择“阿里云盘分享”；

![002-10 配图](images/i04-1671522836-4.avif)

4、找到你想要挂载分享链接，把“https://www.aliyundrive.com/s/”后面的内容全部复制（如下图红框内的内容）；

![002-10 配图](images/i05-1671522836-5.avif)

5、在alist管理后台，填写挂载路径，比如我写的是“/【网友分享】”（名字可以随意写，只要不是重复的就可以），然后把上一步骤复制的内容，在“分享ID”处粘贴；

![002-10 配图](images/i06-1671522837-6.avif)

6、在浏览器新建一个网页窗口，打开【这个地址】，点一下“获取Token”；

![002-10 配图](images/i07-1671522837-7.avif)

7、稍等一下会显示如下的二维码，打开手机，用阿里云盘APP扫码并登录；

![002-10 配图](images/i08-1671522838-8.avif)

8、在手机APP登录成功以后，点网页上的“使用阿里云盘APP扫描然后点击”；

![002-10 配图](images/i09-1671522839-9.avif)

9、在二维码的下方，会显示你当前登录的阿里云盘Token（这个Token非常重要，注意不要泄露！），复制一下；

![002-10 配图](images/i10-1671522839-10.avif)

10、回到alist的管理后台，在刷新令牌处，把上一步骤复制的内容，粘贴进去，然后点“添加”；

![002-10 配图](images/i11-1671522840-11.avif)

11、在浏览器新开一个网页窗口，打开你的alist首页，会看到刚才添加的【网友分享】，点进去；

![002-10 配图](images/i12-1671522841-12.avif)

13、刚才添加的4K-REMUX-电影就在里面了；

![002-10 配图](images/i13-1671522841-13.avif)

14、随便点一个电影，看看能不能播放；

![002-10 配图](images/i14-1671522843-15.avif)

15、可以正常播放；

![002-10 配图](images/i15-1671522843-16.avif)

16、如果遇到这种文件比较大，网页不能在线播放的话，会提示加载失败，需要在电脑上安装客户端进行播放，我电脑已经安装好了PotPlayer，所以我选用PotPlayer来播放；

![002-10 配图](images/i16-1671522844-17.avif)

17、打开PotPlayer专用播放；

![002-10 配图](images/i17-1671522844-18.avif)

18、网页自动会调用电脑的PotPlayer打开播放地址进行播放；

![002-10 配图](images/i18-1671522845-19.avif)

19、可以正常播放了；

![002-10 配图](images/i19-1671522845-20.avif)

【总结】

1、用此方法可以挂载别人分享的链接，并且不占用你自己网盘的空间，缺点就是如果别人分享的链接失效，那么你这个挂载也会跟着失效。但是目前只要阿里云盘不倒，这些资源重新获取应该是不难的，所以这点不用担心。

2、这个方法每次只能添加一个链接，如果链接很多的话，可能你会添加到手软。批量添加分享链接的看《批量添加阿里云盘分享挂载到自己网盘下的教程》；

3、更多玩法：可以用webdav挂载在Win电脑当作本地盘，或者使用手机APP“Infuse”挂载webdav，或者使用emby/jellyfin/plex/kodi等搭建私有的影音库。


本文教你不花一分钱把别人分享的阿里云盘资源挂载到自己网盘且不占空间：利用 alist 的"阿里云盘分享"存储类型，把分享链接 https://www.aliyundrive.com/s/ 后面的分享 ID 填入，再通过网页工具扫码登录获取阿里云盘刷新 Token 填入，即可把网友分享的电影等资源直接挂载到自己的 alist 中在线播放（大文件配合 PotPlayer 等本地播放器）。注意分享链接失效则挂载失效；支持 webdav 挂载到本地盘，或配合 Infuse/Emby/Jellyfin 搭建私有影音库。
