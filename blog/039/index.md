# DNS Checker - DNS Check Propagation Tool

DNS Checker（dnschecker.org）是一个**免费的在线 DNS 与网络诊断工具站**（由 Softrix Technologies 运营，自述为 "Complete DNS & Networking Toolkit"），面向站长、开发者、运维和 SEO 人员，浏览器打开即用、无需注册。

- **旗舰功能 DNS Propagation Checker**：内置 100+ 个覆盖全球各大洲的 DNS 服务器节点（含 Google、Cloudflare、Quad9、OpenDNS 及各地 ISP 解析器），同时向这些节点发起查询，以可视化地图展示"你的 DNS 记录是否已在全球传播生效"，绿色对勾表示已生效、红色叉表示未生效或与预期值不符。
- **支持记录类型**：A、AAAA、CNAME、MX、NS、PTR、SRV、SOA、TXT（SPF/DKIM/DMARC）、CAA、DS、DNSKEY 等。
- **高级特性**：自定义 DNS 服务器、预期值校验（精确/包含/正则）、按大洲/国家筛选、定时自动刷新、结果导出 PNG/JPEG/PDF/SVG。
- **其他工具**：DNS Lookup、NS/MX/CNAME Lookup、WHOIS、IP 查询、IP 黑名单检测、SSL 检查、域名可用性/健康报告等 50+ 款。

dnschecker.org 的价值一句话概括：**改完 DNS 后，用它确认"全球生效了没有"**。适用场景非常明确：换了主机/托管商、新增 MX 邮件记录、部署 SSL 需要验证 CAA/DS、排查某个地区访问异常时，都可以用它从 100+ 全球节点同时看解析结果，地图式展示比手动 nslookup 高效得多。对自建服务用户来说，把域名解析从旧服务器迁到 NAS/新 VPS 后，用这个工具扫一遍即可确认各区域解析是否收敛。注意它是公共工具站，只输入公开域名信息即可，不要提交敏感凭据。
