DNSMap（dnsmap.io）是一个**全球 DNS 传播检测工具站**（由 DigiCert PerfOps 提供），与 dnschecker.org 功能同类。页面自述：

> Check the current IP of your domain name or hostname from multiple DNS nameservers and resolvers from all around the world. Instant propagation check.

- **DNS 传播检测**：从全球不同角落的多个 DNS 服务器/解析器查询你的域名或主机名当前解析到的 IP，即时查看传播结果。
- **免费使用**：提供免费 DNS lookup 服务，针对随机选取的全球 DNS 服务器列表检查域名服务器记录。
- **扩展内容**：站点还提供全局网络测试（Global Network Tests）、DNS 传播相关文章。

dnsmap.io 和 030（dnschecker.org）是同类工具，核心用途一致：**改完 DNS 记录后，从全球多个解析节点确认是否已经生效**。它的特点是查询即时、界面简洁，支持常见记录类型（A/AAAA/CNAME/MX/TXT 等），以全球节点列表/地图形式展示各地区解析结果。使用场景与 dnschecker 高度重叠：域名迁移后验证全球收敛、排查地区性解析不一致、确认新记录覆盖到位。两个工具站可以互为备份——一个被墙或抽风时换另一个查。收藏价值在于给 DNS 排障留一个可用的备选入口。
