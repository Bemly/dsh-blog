文档主要内容（Debug 自检代码速查）：

- **CPU 过热保护**：散热器未正确安装、CPU 温度过高自动断电保护；检查散热器。
- **CPU 故障（CPU 旁红灯）**：排查电源不稳/供电不足、CPU 散热故障、CPU 供电线是否插好；黑群晖引导成功后显示 00、UNRAID 启动完成显示 FF 均属正常（会变化）。
- **内存自检未通过**：B0/B1/B7/B9/BA/BD 等为内存位置错误、不兼容或读取不到，重新拔插或更换内存测试；部分内存锁定高频无法降 2133 可能随机卡 B7；BA/BD 常见于双路主板，频率或容量超标时减少内存。
- **显卡报错（来回跳 d6 伴随连续报警声）**：重新拔插或更换显卡；显卡报错不影响系统正常启动和使用；只支持 UEFI 的显卡参考 mi-d.cn/9608 设置 BIOS。
- **BIOS 自检未通过（19/79/96）**：断电按一下 I/O 挡片介于 USB 与网口之间的 CMOS 按键再测试；若重复则 BIOS 损坏或脱焊，拔掉所有内存和 PCIE/USB 设备再开机，还卡就是 BIOS 问题需重刷。
- **Ab/AE/Ad**：已通过自检，分别在 BIOS 界面、载入引导界面、已进入 DOS。
- **AA/55/72/73/23/40/00/FF**：黑群晖引导成功显示 00、UNRAID 启动完成显示 FF、ESXi/PVE 显示 AA；系统长时间运行代码可能变 92。
- **硬盘卡自检（92）**：拔掉或更换硬盘。
- **USB 设备卡自检（B4/84）**：USB 短路或供电电流过大，拔掉所有 USB 设备重新测试；详见 mi-d.cn/9601。
- **PCIE 设备冲突（84）**：拔掉部分 PCIE 设备再测试，PCIE 不得插显卡（原文如此）。
- **温控芯片故障（99）**：温控芯片故障或风扇接错线短路。
