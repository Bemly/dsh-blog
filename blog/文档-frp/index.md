本链接为 **frp 官方文档站**（gofrp.org），收藏路径 `/docs/` 当前跳转到站点中文首页。frp 是广为人知的开源内网穿透工具，页面核心内容如下：

- **简介**：简单、高效的内网穿透工具。
- **简单易用**：frp 采用 C/S 模式，将服务端部署在具有公网 IP 的机器上，客户端部署在内网或防火墙内的机器上，通过访问暴露在服务器上的端口，反向代理到处于内网的服务。
- **功能强大**：支持 TCP, UDP, HTTP, HTTPS 等多种协议，提供了加密、压缩、身份认证、代理限速、负载均衡等众多能力。
- **灵活配置**：支持多种代理类型以及 P2P 通信，还可以通过 xtcp 实现点对点通信，为不同场景提供丰富的解决方案。
- **下载**：从 Github Release 页面下载最新版本。
- **参与贡献**：在 Github 上提交 Issue 和 Pull Request；关注作者 @fatedier 获取最新动态。


frp 是自建 NAS 玩家实现「外网访问内网服务」的标配工具之一：服务端部署在任意有公网 IP 的云服务器上，客户端装在家里 NAS/软路由/树莓派上，即可把内网的 Web、SSH、远程桌面等服务安全地暴露出去；xtcp 模式还能实现不经过服务器中转的点对点直连，流量几乎不绕路。收藏路径是官方文档站，适合查阅配置示例、代理类型（tcp/udp/http/https/stcp/xtcp）与进阶功能。该分类下可与之配套的工具还有 Tailscale（组网）、nat123（免费域名零配置）等，frp 的优势是协议全面、配置灵活、完全开源自部署。
