### 什么是备用 DNS？

辅助 DNS 提供了一种将域名的 DNS 流量分配给两个或多个 DNS 提供商的方法，以非常简单友好的方式实现尽可能最佳的正常运行时间和冗余。它为您提供了一组额外的权威 DNS 服务器，这些服务器可以响应传入的域名请求。您只能在单个（主 DNS）提供商处管理域名的 DNS 记录，使用辅助 DNS 技术的第二个提供商可以保持最新并自动同步。

每个域名都需要一个主 DNS 服务器来保存每个精确域的所有可用资源记录，并对其 DNS 查询作出响应。但是，为了更快的加载时间、改进的负载平衡以及在发生 DNS 中断或恶意攻击时的冗余，让许多域所有者都信任辅助 DNS。

### 使用备用 DNS 服务的优势

设置辅助 DNS 的一些主要好处包括：

- **100% 正常运行时间**：如果主 DNS 服务提供商不可用，DNS 流量将会自动转到备份服务提供商，而且对网站的访问者看起来不会有任何可视化影响
- **备份**：如果主提供商出现问题，可以将辅助 DNS 用作备份计划，拥有所有 DNS 记录的新副本
- **提供商中立**：近年来 DDoS 攻击在频度与严重性上都在增长，追加额外的 DNS 服务提供商来使用备用 DNS 带来更好的安全性和提供商的独立性
- **附加的安全**：如果您管理自己的 DNS 服务器，可以通过隐藏的主服务器来注册辅助 DNS 从而达到保护它们，ClouDNS 将为您处理好所有的公共流量
- **提高了性能**：辅助 DNS 可以通过将流量分布在多个服务器上来提高网站的性能
- **易于迁移**：添加一个备用 DNS 是相当简单的过程，无需更改管理系统、访问及控制面板信息，非常透明地迁移到 DDoS 防御和 Anycast DNS
